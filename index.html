Install

Two minutes, once.

  1. Download the win-x64.exe and open it.
  2. If Windows warns you: More info › Run anyway.
  3. Continue with Google, with the account a partner added.
  4. It lives in the tray and updates itself.
  1. Open the .dmg, drag Studio Desk into Applications.
  2. First open: System Settings › Privacy & Security › Open Anyway.
  3. Sign in with Google. Keychain asks? Always Allow.
  4. It lives in the menu bar.

New version out? The menu shows Download update. Drag it into Applications and choose Replace. Apple chip = arm64, Intel = x64.
